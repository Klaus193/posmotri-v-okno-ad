# Проектная работа «Посмотри в окно»

Учебный проект, выполненный в рамках курса «Веб-разработчик» в Яндекс Практикуме.

## Функциональность
Интерактивное приложение для поиска видео по городу и времени суток. Реализована работа с API, динамическая отрисовка карточек, прелоадеры и обработка ошибок.

## Технологии
- HTML5
- CSS3 (Flexbox, Grid, кастомные элементы форм, состояния `:focus-visible`)
- JavaScript (работа с DOM, Fetch API)
